## Data Download
The data are on Zenodo (DOI 10.5281/zenodo.24214090) as three archives. Download only the
ones you need. `scripts/fetch_data.sh` downloads each archive and unzips it into its place
in `data/`.

| Archive | Download | Contents | Needed for | Command |
|---|---|---|---|---|
| `rubric_data.zip` | 330 MB | the processed data behind every figure and table | every notebook, and every script that does not read structure files | `bash scripts/fetch_data.sh` |
| `rubric_structures.zip` | 5.2 GB | the mmCIF files in `data/structures/` (the 2,696 non-redundant entries, 1GID for Fig. S12, the NMR entries in `nmr/` and the other entries the analyses read in `engine_cache/`) and the PDB-REDO models in `data/validation/redo_files/` | running RUBRIC on the structures: feature extraction, scoring, the PDB-REDO comparison, the runtime benchmark | `bash scripts/fetch_data.sh structures` |
| `rubric_program_runs.zip` | 1.7 GB | the output of every run of the six annotation programs and of RUBRIC, in `data/comparison/program_runs/` | rebuilding the comparison with six programs without installing them (see [`scripts/comparison/README.md`](scripts/comparison/README.md)) | `bash scripts/fetch_data.sh program_runs` |

`bash scripts/fetch_data.sh all` downloads all three. If a download is interrupted, run the
same command again to continue it. The archives can be fetched in any
order and at any time, since each one adds only its own folders. Files that already exist in
`data/` are never replaced or deleted; to restore the deposited version of a file, delete it
and fetch again.

With all three archives, every step can be rerun on the exact files used in the paper,
without downloading from the RCSB PDB or PDB-REDO and without installing the annotation
programs.

## Installation
Requires Python 3.11 or newer.

```bash
git clone https://github.com/YesselmanLabPublications/2026_Rubric_paper
cd 2026_Rubric_paper

# Create a new conda environment (also works with mamba / micromamba)
conda env create -f environment.yml
conda activate rubric-analysis

# or, without conda
# pip install -r requirements.txt -r requirements-engine.txt

# Download the data the notebooks need (rubric_data.zip) into data/
bash scripts/fetch_data.sh
```

`requirements-engine.txt` installs the RUBRIC version used in the paper
(`rubric-rna==1.0`).

The tests need no data and run in a few seconds:

```bash
pytest
```

## Running the analysis
The figures need only the downloaded data. The steps below regenerate that data,
from the scoring tables up to raw structures. Run them from the repository root.

### Rebuild the scoring tables
Rebuilds the ProSco, Z′, backbone and penalty-weight tables in
`data/reference/scoring_tables/` from the feature tables (no RUBRIC needed).

```bash
cd scripts/data_gen
python build_distributions.py
python build_prosco_distributions.py
python build_z_tables.py
python build_backbone_distributions.py
python calculate_penalty_weights.py   # run last; reads the tables above
```

### Regenerate the feature tables from raw structures
Extracts the per-pair and per-residue features with RUBRIC 1.0. Reads the
structure files in `data/structures/`, which come with `rubric_structures.zip` (see Data Download).

```bash
cd scripts/data_gen
python extract_pair_features.py
python extract_backbone_torsions.py
```

Then rebuild the scoring tables (above) and re-run the notebooks.

### Validation, tool comparison and runtime benchmark
The PDB-REDO validation, the comparison with six annotation programs and the
runtime benchmark have their own scripts, described in
[`scripts/README.md`](scripts/README.md),
[`scripts/comparison/README.md`](scripts/comparison/README.md) and
[`scripts/benchmark/README.md`](scripts/benchmark/README.md).
`scripts/README.md` also lists what each script writes and describes the
contents of `data/`.

## Repository layout
```
notebooks/
  figures/                one notebook per main figure (Figures 1-4)
  supplemental_figures/   one notebook per supplementary figure (Figures S1-S12)
figures/
  main/                   main figures as PNG, combined and per panel
  supplemental/           supplementary figures as PNG, combined and per panel
source_data/              the values behind selected panels (CSV)
scripts/
  fetch_data.sh           downloads the data archives from Zenodo into data/
  data_gen/               feature extraction with RUBRIC and the scoring-table builds
  reference/              reference sets and RUBRIC scores of the non-redundant and NMR sets
  validation/             comparisons with higher-resolution and PDB-REDO models, and other validation tables
  comparison/             comparison with six annotation programs (see its README)
  benchmark/              runtime benchmark (see its README)
  pymol_figures/          PyMOL renders of the example pairs in Figures S8 and S9
tests/                    pytest suite
data/                     from the Zenodo archives, not tracked in git (described in scripts/README.md)
```
